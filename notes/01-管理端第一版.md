# 管理端第一版

## 实现功能与规则

- 创建独立 Vue 3 管理端，开发端口为 `5174`，通过 Vite 代理访问后端。
- 登录时校验账号必须为 `ADMIN`，本地会话与客户端项目隔离，过期后自动清理。
- 在应用入口全局注册 Element Plus，确保表单、按钮、图标等管理端组件能够正常渲染。
- 支持 Chat、Embedding 模型的新增、编辑、连接测试、启停和分别设置默认项。
- 支持知识库创建与空库删除，以及文档上传、分块预览、异步索引、状态轮询和删除。
- 支持调整三个知识库级检索参数，并展示 BM25、KNN 和 RRF 融合结果。
- 检索参数使用横向滑杆调整，向量相似度在界面中统一使用百分数表达。
- 向量相似度过滤始终启用，不再维护重复的开关状态；最低 0% 会过滤负相关向量。
- 召回测试先展示紧凑的 Chunk 列表，点击某项后在侧边栏查看完整内容和各路得分。

## 主要文件职责

- `src/components/layout/AdminLayout.vue`：后台导航、页面标题和管理员菜单。
- `src/views/ModelConfigsView.vue`：模型配置完整管理流程。
- `src/views/KnowledgeBasesView.vue`：知识库列表和创建入口。
- `src/views/KnowledgeBaseDetailView.vue`：文档、检索参数和召回测试工作区。
- `src/api/`：封装认证、模型和知识库接口。
- `src/types/`：维护后端请求与响应的 TypeScript 类型。
- `src/styles/index.css`：管理端独立视觉系统和布局样式。
- `src/main.ts`：注册 Pinia、路由与 Element Plus 全局组件。

## API 影响

本次只新增前端项目，没有修改后端接口或数据库。页面使用现有 `/api/auth/login`、`/api/admin/model-configs` 和 `/api/admin/knowledge-bases` 接口。
