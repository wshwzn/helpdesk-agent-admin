# 批量上传知识文档

## 实现功能与规则

- 文档管理入口改为“批量上传”，在弹窗中支持拖拽文件和多选文件。
- 单次最多添加 20 个文档，继续遵循 `txt`、`md`、`pdf`、`docx` 和单文件 20 MB 限制。
- 上传前在浏览器校验格式与大小，不合法文件不会进入队列。
- 点击一次上传后按队列逐个调用现有接口，避免多个大文件同时占用服务端内存。
- 单个文件失败不会中断后续文件；失败项会保留在列表中，可以直接重试。
- 全部完成后只刷新一次知识库和文档列表，避免每个文件重复刷新页面。

## 修改文件

- `src/views/KnowledgeBaseDetailView.vue`：增加批量上传弹窗、拖拽队列、客户端校验和逐文件状态处理。

## API 影响

没有新增后端接口。管理端复用 `POST /api/admin/knowledge-bases/{id}/documents`，每个文档仍是独立请求和独立事务。

## 验证

- `npm run test`：3 项测试通过。
- `npm run build`：生产构建成功。

## 已知限制

- 当前按顺序上传文件，没有并发上传和整批取消功能。
- 上传完成后仍需按现有流程逐个触发文档索引。
