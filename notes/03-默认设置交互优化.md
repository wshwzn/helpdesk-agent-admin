# 默认设置交互优化

## 实现功能与规则

- 修复知识库卡片右上角操作按钮点击后仍跳转详情的问题。
- 菜单按钮由独立容器阻止点击冒泡，卡片其他区域仍可正常进入详情。
- 模型卡片右上角直接展示“设为默认”按钮；已经是默认项时显示“默认模型”标识。
- 禁用的模型保留默认按钮但不可点击，并提示需要先启用模型。

## 修改文件

- `src/views/KnowledgeBasesView.vue`：隔离菜单点击事件并补充按钮可访问名称。
- `src/views/ModelConfigsView.vue`：把默认模型操作移动到卡片头部。
- `src/styles/index.css`：补充菜单层级和默认操作布局。

## API 与数据影响

本次只调整管理端交互，没有修改后端接口、数据库或本地存储。

## 验证

- `npm run test`
- `npm run build`

## 已知限制

模型必须先启用才能设为默认，该限制与后端规则保持一致。
