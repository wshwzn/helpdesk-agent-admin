# 批量开始文档索引

## 实现功能与规则

- 文档列表增加多选列，可以一次勾选当前页中的多个文档。
- 只有“待索引”和“失败”状态的文档可以加入批量队列，避免误重建已就绪文档，也不会重复提交处理中的任务。
- 点击“批量开始索引”后按顺序调用已有单文档索引接口；单个文档失败不会中断其他文档。
- 操作完成后统一刷新列表，并汇总成功、失败数量和首个失败原因。
- 已就绪文档继续通过行内“重新索引”单独操作。

## 修改文件

- `src/views/KnowledgeBaseDetailView.vue`：增加文档多选、批量索引队列、状态限制和结果汇总。
- `src/styles/index.css`：补充文档工具栏多按钮布局。

## API 影响

没有新增后端接口。管理端对每个选中文档复用 `POST /api/admin/knowledge-bases/{knowledgeBaseId}/documents/{documentId}/index`。

## 验证

- `npm run test`：3 项测试通过。
- `npm run build`：类型检查和生产构建通过。

## 已知限制

- 批量选择范围是当前分页，每页最多 20 个文档。
- 请求按顺序提交，页面关闭后前端不再继续提交尚未开始的文档；已经提交到后端的异步索引任务不受影响。
