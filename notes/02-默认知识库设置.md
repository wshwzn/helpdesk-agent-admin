# 默认知识库设置

## 实现功能与规则

- 知识库卡片显示当前默认标识。
- 管理员可以从卡片菜单把任意知识库设为默认项，成功后立即刷新整个列表。
- 系统只保留一个默认知识库，客户对话中的 RAG 工具由后端读取该配置。

## 新增和修改文件

- `src/types/knowledge.ts`：知识库响应增加 `isDefault` 字段。
- `src/api/knowledge.ts`：封装设为默认知识库接口。
- `src/views/KnowledgeBasesView.vue`：增加默认标识和设置操作。
- `src/styles/index.css`：补充默认标识布局。
- `README.md`：补充默认知识库管理能力。

## API 影响

- 使用后端新增的 `POST /api/admin/knowledge-bases/{id}/default`。
- 没有新增管理端环境变量或本地存储字段。

## 验证与限制

- 已执行 `npm run test` 和 `npm run build`。
- 当前只支持一个全局默认知识库；后续增加 Agent 配置后再扩展多知识库绑定。
