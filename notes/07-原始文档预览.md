# 原始文档预览

## 实现功能与规则

- 文档列表新增“查看原文”，在独立管理端标签页加载文档；原“预览”明确改名为“分块预览”。
- PDF 使用浏览器内置阅读器，TXT 和 Markdown 保留原始文本格式，DOCX 使用 `docx-preview` 在浏览器内渲染。
- 预览页展示文件名、格式和大小，并支持按原文件名下载。页面离开时会释放临时 Blob 地址。
- 原文件通过携带管理员 JWT 的后端接口读取，不拼接或暴露 OSS 地址；加载失败可在当前页重试。

## 新增文件

- `src/views/KnowledgeDocumentOriginalView.vue`：原文加载、格式分流、DOCX 渲染和下载页面。
- `src/utils/document-preview.ts`：按扩展名判断预览方式。
- `src/utils/document-preview.test.ts`：覆盖四种支持格式和未知格式。

## 修改文件

- `src/api/http.ts`：新增携带登录态的二进制请求与 Blob 错误解析。
- `src/api/knowledge.ts`：新增单文档元数据和原文内容请求。
- `src/router/index.ts`：新增受登录保护的原文路由。
- `src/views/KnowledgeBaseDetailView.vue`：新增原文入口并区分分块预览。
- `src/styles/index.css`：新增独立预览页和 DOCX 纸张样式。
- `package.json`、`package-lock.json`：加入 `docx-preview`。

## API 影响

- 使用后端新增的单文档元数据接口与原始文件流接口，二者均要求 ADMIN 身份。

## 验证

- `npm run test`：2 个测试文件、5 项测试通过。
- `npm run build`：TypeScript 类型检查和生产构建通过。

## 已知限制

- Markdown 当前按原始文本查看，不渲染为 HTML，避免引入不必要的脚本注入面。
- PDF 展示能力取决于浏览器内置阅读器；不支持的环境仍可下载原文件。
